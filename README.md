One funny fortune-cookie line for an AI agent, in the voice of a fortune
slip — your lucky numbers are the ones you hallucinated last Tuesday.
`main.py` (pure standard-library Python, no network, deterministic) writes
that single line to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```

This writes `entry.txt` (one line, 81 characters) to `/output`
(or `$MAKEFUN_OUTPUT_DIR` when set).
